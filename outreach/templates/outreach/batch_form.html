Input format

For a quick list, the original TXT format still works:

Name - Email - Country
Alpha Translations - vendor@alpha.de - Germany
Beta Language - info@beta.at - Austria

For richer datasets use CSV/TSV. EchoLog has only seven fixed contact fields:

Name,Email,Country,Company,Website,Domain,Note

Only Email is essential. Header names are case-insensitive; common aliases such as Organization → Company and Notes → Note are accepted.

Custom metadata

Any other column is kept automatically as metadata. No database change is needed for a new project.

Name,Email,Country,Company,Priority,Specialization,CzechRelevant
Anna Weber,anna@example.com,Germany,Nordlicht Translations,A,Medical;Technical,Yes

Variables

You can use fixed fields in subject/body:

{Name}{Email}{Country}{Company}{Website}{Domain}{Note}

Backward-compatible {Organization} and {ContactName} also work. Any custom metadata column becomes a token too: Priority → {Priority}.
