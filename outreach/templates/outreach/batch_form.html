Input format

The easiest TXT format is one recipient per line:

Name - Email - Country
Alpha Translations - vendor@alpha.de - Germany
Beta Language - info@beta.at - Austria

CSV/TSV is also accepted. Recommended headers:

name,email,country

Variables

You can use these in subject and body:

{Name}{Organization}{ContactName}{Email}{Country}

Unknown/missing values become empty text. Preview the first messages before starting.
